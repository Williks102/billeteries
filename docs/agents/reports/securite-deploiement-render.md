TRUSTED_PROXIES="*" : vendor/laravel/framework/.../TrustProxies.php:112-115 transforme '*' en « seul REMOTE_ADDR (pair direct) est de confiance » ; Symfony retient alors la valeur la plus à DROITE non fiable de X-Forwarded-For. Une valeur forgée à gauche est donc ignorée : pas de contournement trivial des throttles. Non vérifiable ici : la composition exacte de la chaîne Render (si l'entrée la plus à droite est une IP de bord/CDN, les quotas par IP deviennent partagés, pas contournables). Le conteneur écoute sur 0.0.0.0:$PORT ; l'accès direct dépend du réseau privé Render (non vérifiable dans le code).

Correctif : le guide doit demander de passer DEMO_SEED=false après le premier déploiement (déjà en checklist l.146, à mettre dans « Premier démarrage »). Agent : devops.
